# Expo React Native Starter (TypeScript)

This is a minimal, mobile-only starter template using Expo, React Native, and TypeScript.

Quick start

```bash
npm install
npx expo start
```

Run on device/simulator using Expo Go or `expo run:android` / `expo run:ios`.

Notes

- Navigation: native stack + bottom tabs
- Styling: React Native `StyleSheet` only
- Mock data only (no backend)
